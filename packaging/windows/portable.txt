yorusphoto portable mode

While this file sits next to yorusphoto.exe, yorusphoto keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the yorusphotoData folder beside it, and writes
nothing to %APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move yorusphoto with its settings.

Delete this file to use the normal per-user folders instead: %APPDATA%\yorusphoto for settings
and %LOCALAPPDATA%\yorusphoto\Recovery for crash-recovery autosaves. If yorusphotoData can't be
written (for example on a read-only drive), yorusphoto says so and uses those folders instead.

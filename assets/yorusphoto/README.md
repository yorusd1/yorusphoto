# yorusphoto branding

`logo.png` is the original image supplied by the user. The two icon PNGs and
`yorusphoto.ico` are resized encodings of that same image, with its appearance and
background preserved. The ICO includes 16, 24, 32, 48, 64, 128, and 256 pixel sizes.

Regenerate with `prepare-assets.ps1 -SourcePath <original.png>` on Windows.
See `LICENSE-brand.txt` for the asset's separate rights notice.

yorusphoto portable mode

While this file sits next to yorusphoto.exe, yorusphoto keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the yorusphotoData folder beside it, and writes
nothing to %APPDATA%. Copy the whole folder to move yorusphoto with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\yorusphoto) instead.
If yorusphotoData can't be written (for example on a read-only drive), yorusphoto says so and
uses %APPDATA%\yorusphoto instead.
